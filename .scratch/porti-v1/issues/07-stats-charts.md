# 07: 收益统计页

**What to build:** 收益统计页：总资产与累计收益两条时间曲线（ECharts，X 轴为有净值记录的日期，导入的 3–8 月历史即有数据）；周收益列表（最新净值记录日 vs ≥7 天前最近记录日的市值差）；单只基金盈亏排序图。新增净值/流水后自动更新。

**Blocked by:** 01（项目脚手架与数据库初始化）、02（计算引擎）、03（Excel 导入与对账）

**Status:** ready-for-agent

- [ ] 两条曲线渲染正确，覆盖导入的 3–8 月历史区间
- [ ] 周收益与手算一致（抽查至少 2 个日期）
- [ ] 单基金盈亏排序正确，与持仓数据一致
