# 05: 净值管理页与联网抓取

**What to build:** 净值管理页：每只基金一张净值历史表（日期/净值/来源）；「一键抓取」按钮为全部持仓基金从公开行情接口拉取最新净值并写入（auto 来源）；应用启动时自动尝试抓取（失败静默不阻塞）；支持手动补录某只基金某日的净值（manual 来源），同基金同日已有记录时给出明确处理方式。
