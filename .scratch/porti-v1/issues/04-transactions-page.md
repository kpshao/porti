# 04: 交易流水页

**What to build:** 完整的交易流水管理：列表展示全部流水并支持按基金/日期/操作类型筛选排序；支持新增、编辑、删除四种操作类型（买入/卖出/分红现金/分红再投入）的流水；录入时从基金列表选择基金、可内联新建基金；按类型校验字段（分红现金：金额正、份额空；分红再投入：金额空、份额正）；任何改动后总资产/盈亏等汇总数字实时重算。

**Blocked by:** 01（项目脚手架与数据库初始化）、02（计算引擎）、03（Excel 导入与对账）

**Status:** resolved

- [x] 列表展示导入的 69 笔流水，筛选与排序可用
- [x] 四种操作类型均可新增，字段校验规则正确（含手续费默认 0）
- [x] 编辑与删除历史流水可用，汇总数字实时重算
- [x] 录入时可从基金列表选择；列表中没有的基金可内联新建（代码 6 位校验）
- [x] 新建一笔流水后，计算引擎输出与手算一致

## Comments

- **手续费口径说明**（对齐 spec「手续费计入成本」）：金额字段即含手续费的实付总额，净投入成本 = Σ金额（与 Excel 流水口径一致），引擎不重复累加手续费；表单已标注「金额（元，含手续费）」，服务层测试含手续费用例（金额 1002 = 份额 100 × 净值 10 + 手续费 2 → 净投入成本 1002）。
- **校验规则**：买入金额/份额正；卖出录入正数库内取负；分红现金金额正、份额强制置空；分红再投入金额须为空（按 0 计）且份额正；手续费留空默认 0；净值可选但须为正；基金代码 6 位补零；新建基金大类须为固守+/纯债/权益/黄金/流动性封闭集合。规则集中在 engine/validation，主进程服务与界面共用。
- **汇总实时重算**：任何增删改后全量重拉并走计算引擎现算（非快照）。
- **清理**：移除 M1 遗留的 data:summary 死 API，统一为 tx:data。
