# 年化收益率（XIRR）

## Problem Statement

用户目前只能看到全期累计口径的「总收益率」和周收益，无法回答「我的钱投了这么久，年化回报是多少」；分批买入/定投场景下，累计收益率也不适合横向比较资金效率。缺少单只基金与整体两个层面的年化收益率视图。

## Solution

新增资金加权年化收益率（XIRR）：单只基金在概览页持仓明细中新增「年化收益率」列；整体在概览页与交易流水页顶部统计区新增「年化收益率」卡，并将现有「总收益率」卡改名「累计收益率」以区分两个口径。已清仓基金的历史现金流计入整体年化。

## User Stories

1. 作为持仓者，我想在概览页持仓明细中看到每只基金的「年化收益率」，以便比较不同基金的资金使用效率。
2. 作为持仓者，我想在概览页顶部看到整体的年化收益率，以便了解全部投入资金的年化回报水平。
3. 作为用户，我想在交易流水页顶部也看到整体年化收益率，以便录入流水后立即核对年化的变化。
4. 作为定投用户，我希望年化按资金加权（XIRR）计算，以便分批买入的钱不被最近大额投入简单摊薄。
5. 作为用户，我希望买入按现金流出、卖出与分红现金按现金流入参与计算，以便年化反映真实的资金进出。
6. 作为用户，我希望分红再投入只增加份额、不制造现金流，以便年化口径与「成本不变」的现有记账约定一致。
7. 作为用户，我希望已清仓基金的完整现金流（含卖出回款）计入整体年化，以便已落袋的历史收益不被抹掉。
8. 作为用户，我希望持仓不足 30 天的基金（以及整体首笔流水不足 30 天时）年化显示「—」，以免被短期放大的数字误导。
9. 作为用户，我希望「总收益率」卡改名「累计收益率」，以便与「年化收益率」明确区分。
10. 作为用户，我希望年化收益率的显示格式与盈亏比例一致（两位小数百分比、正红负绿），以便快速判断正负。
11. 作为用户，我希望个别数据异常（无净值记录、现金流无法收敛、负净成本）时显示「—」而非报错，以便页面始终可用。
12. 作为用户，我希望新增/修改流水、补录净值后年化收益率自动更新，与其他汇总数字行为一致。
13. 作为新用户，我希望导入 Excel 后无需额外操作即可看到年化收益率，以便迁移历史数据的同时获得新指标。
14. 作为用户，我希望没有数据或汇总为空时页面行为与现状一致（不渲染统计卡），年化不引入新的空态问题。
15. 作为维护者，我希望年化计算是带手算黄金值的纯函数，以便将来调整口径时有回归保障。

## Implementation Decisions

- **口径**：XIRR（资金加权年化）——求 r 使全部现金流按 (1+r)^(天数/365) 折现后的净现值为 0，r 即年化收益率。
- **现金流规则**：买入为流出（金额为正、已含手续费）；卖出为流入（库内金额存负值，取绝对值）；分红现金为流入；分红再投入金额恒为 0、不产生现金流，其份额计入期末估值。
- **期末估值**：单基金 = 当前份额 × 最新净值（完全沿用现有市值口径）；整体 = 全部持仓市值之和。无净值记录的持仓市值不计入期末估值。期末估值日 = 「今天」。
- **最短持有期**：单基金首笔现金流日距今天不足 30 天 → 单基金年化为空；全库首笔流水日距今天不足 30 天 → 整体年化为空。空值界面显示「—」。
- **整体范围**：全部历史流水（含已清仓基金的卖出回款与分红现金），不限于当前持仓。
- **契约**：概览页与流水页的数据契约各新增一个年化字段（按基金代码的年化映射 + 整体年化），在既有数据 handler 中组装；界面类型随共享类型流动，无需新增 IPC 通道。
- **计算层**：在计算引擎新增独立纯函数（XIRR 核心求根 + 单基金年化映射 + 整体年化），「今天」显式入参以保证可测；现有持仓/汇总/时间序列函数的签名与口径不动。
- **收敛与异常**：数值求根不收敛或无解、负净成本等异常一律返回空值。
- **命名**：现有「总收益率」卡改名「累计收益率」（仅界面标签；导入对账表沿用 Excel 口径标签不变）。
- **界面**：概览页持仓明细在「盈亏比例」后新增「年化收益率」列（仅当前持仓行，即份额非零）；概览页与流水页顶部统计区新增第 5 张卡「年化收益率」，放在「累计收益率」卡之后。

## Testing Decisions

- **好测试的标准**：只测函数输入 → 输出的外部行为（手算期望值），不测求根迭代的内部细节。
- **测试落点**：计算引擎纯函数测试，沿用既有 compute.test.ts 的手算黄金值风格（同类先例还有 exportService.test.ts、validation.test.ts）。
- **必测用例**：单笔买入已知期末估值的 XIRR 手算值；多笔定投；含卖出与分红现金；分红再投入不改变结果；30 天门槛边界（恰好 30 天显示、29 天为空）；无净值记录不入期末估值；整体含已清仓基金；不收敛返回空；负净成本返回空。
- **渲染层**：仓库无渲染层单测先例，界面改动（列/卡/改名）以手工验收与既有冒烟脚本覆盖。

## Out of Scope

- 严格成本法（已实现/未实现盈亏分离、移动加权成本）仍留待 V2；既有「总收益率」口径矛盾本次不改。
- 区间净值年化（近一年/今年以来）不做。
- 最新净值陈旧提醒不做；持有天数展示不做。
- 收益统计页年化曲线不做。
- 导出的概览表不新增年化列。
- 基金详情页不做。

## Further Notes

- 领域词汇沿用 CONTEXT.md：流水（买入/卖出/分红现金/分红再投入）、净值；空值统一显示「—」。
- 「累计收益率」仅指界面标签重命名；数据字段与计算口径不变。
- 年化收益率对最新净值敏感（终值随净值变化）；净值陈旧时用户可通过净值管理页补录刷新。
