# 04: 每一笔卖出各自锁定了多少，看得见

**What to build:** 用户在交易流水页看到每笔卖出行自带一个「本笔已实现」金额，能据此追溯概览那个累计数从哪来；在保存一笔卖出之前，表单里就实时显示本笔已实现收益——在唯一能反悔的时刻知道自己做了什么。口径必须与概览的累计值同源，不得另写一套。

**Blocked by:** 01（列名与卡片名同源）

**Status:** ready-for-agent

- [ ] 引擎新增按笔计算已实现收益的能力，复用现有成本推进口径（同一套移动加权平均），累计值与此前完全一致
- [ ] 交易流水表卖出行显示「本笔已实现」；非卖出行留空
- [ ] 卖出表单在保存前实时预览本笔已实现收益
- [ ] 引擎测试（手算黄金值）：单笔全清；多次买入 + 部分卖出；清仓后再买一笔再卖；同基金多笔卖出的归属正确
- [ ] `npm test` + `npm run typecheck` 全绿
- [ ] 跑起应用目视确认：录一笔卖出，表单预览与流水表列的值一致，且与概览累计值对得上
