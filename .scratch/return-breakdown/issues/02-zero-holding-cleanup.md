# 02: 清仓基金不再留僵尸行，也不凭空占配置比例

**What to build:** 用户清仓一只基金后，概览的持仓明细表不再出现那行全 0、比例为空的行；需要回顾时可通过「显示已清仓」开关把它找回来，并能继续点进基金详情看完整战绩与历史。同时，某个大类被清空后，「实际投入比例」按该大类当前是否还有市值判定——已清空记 0，不再显示由历史亏损造成的、永远消不掉的偏离。

**Blocked by:** None（可立即开工）

**Status:** ready-for-agent

- [ ] 默认不显示零持仓基金行；开关打开后可见，且仍可从该行点进基金详情
- [ ] 零持仓基金不被删数据、不被从计算中剔除（基金详情入口依赖它存在）
- [ ] 大类「实际投入比例」只统计当前仍有市值的持仓；某大类清空后其比例与该大类的偏离均为 0
- [ ] 引擎测试覆盖：单一大类清仓后比例记 0；混合场景（部分大类清仓）分母正确
- [ ] `npm test` + `npm run typecheck` 全绿
- [ ] 跑起应用目视确认：清仓基金行消失、开关能找回、大类比例不再显示凭空的偏离
