# 配置目标只在大类层存在（删除单只基金目标金额）

概览页曾有「目标金额（元）」列：单只基金的期望金额，可编辑、随 Excel 导入导出。它从未参与任何计算或比较——没有偏离、没有达成率；真正有对照物的是大类目标比例（实际市值占比 − 目标比例 = 偏离）。原始 spec 曾以「配置对比有基准」为由要求维护它，但单只基金的对比从未实现，属于 spec 与实现的矛盾。选择删除而非补对比：用户已填的 9 个数值从未用于决策，说明缺口不在「少一个偏离列」而在该概念不在工作流里；持仓表已 12 列、宽度紧张，补一张单只基金配置表只会增加维护成本。代价：schema 版本升至 2，删列前自动备份，旧版迁移包导入时该列数据被丢弃；导入器仍接受原有 Excel（忽略该列），导出不再包含该列。

**Consequences**: 配置目标只在大类层表达（目标比例 + 偏离），单只基金不设目标；`CONTEXT.md` 以「大类目标比例」为唯一目标词条。若未来需要单只基金再平衡，应以「目标偏离/达成率」的完整对比形态重新引入，而不是恢复一个孤立数字。
