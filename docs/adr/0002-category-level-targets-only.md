# 配置目标只存在于配置桶层（删除单只基金目标金额）

概览页曾有「目标金额（元）」列：单只基金的期望金额，可编辑、随 Excel 导入导出。它从未参与任何计算或比较——没有偏离、没有达成率；真正有对照物的是配置目标比例（实际市值占比 − 目标比例 = 偏离）。原始 spec 曾以「配置对比有基准」为由要求维护它，但单只基金的对比从未实现，属于 spec 与实现的矛盾。选择删除而非补对比：用户已填的 9 个数值从未用于决策，说明缺口不在「少一个偏离列」而在该概念不在工作流里；持仓表已 12 列、宽度紧张，补一张单只基金配置表只会增加维护成本。代价：schema 版本升至 2，删列前自动备份，旧版迁移包导入时该列数据被丢弃；导入器仍接受原有 Excel（忽略该列），导出不再包含该列。

**修订（schema v5 / v6）**: 目标原先只在大类层设置；三层模型（账本大类 / 产品形态 / 配置桶）落地后，目标移到配置桶层（稳健 / 权益 / 黄金），见 ADR-0004。schema v5 新增 `bucket_targets`；schema v6 收缩旧模型时，旧分类目标先归一化、再按固收+ 的默认权益系数折算为三桶目标并写入配置桶，随后删除旧目标表，因此不再有一次性确认。目标合计不等于 100% 时只警告，偏离按归一化目标计算；合计为 0 视为未配置，偏离为空。

**Consequences**: 配置目标只在配置桶层表达（目标比例 + 偏离），单只基金不设目标；`CONTEXT.md` 以「配置桶目标比例」为唯一目标词条。若未来需要单只基金再平衡，应以「目标偏离/达成率」的完整对比形态重新引入，而不是恢复一个孤立数字。
