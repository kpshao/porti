# 三层分类模型与配置桶权益穿透

旧五类把两种维度混在一层：固守+ / 纯债描述产品形态，权益 / 黄金 / 流动性描述风险暴露。结果是配置对比固定出现五个大类、固收+ 内部的权益仓位没有穿透、权益暴露被低估，目标合计还可能不是 100%。现在拆成三层固定词汇：**账本大类**（债 / 权益 / 黄金）决定市值落入哪个桶，**产品形态**（固收+ / 纯债 / 权益 / 黄金）供持仓列表分组与用户辨认，**配置桶**（稳健 / 权益 / 黄金）只服务配置对比。账本大类由产品形态派生并有固定映射：固收+ / 纯债 → 债，权益 → 权益，黄金 → 黄金；产品形态与账本大类不一致的组合在写入层拒绝。

每只基金维护 0–1 的**权益系数**（界面按百分比编辑），默认按产品形态给出：固收+ 20%、纯债 0%、权益 100%、黄金 0%，允许逐只覆盖；同时记录**系数来源**（手工 / 抓取）与**系数数据日期**（报告期或空）。配置桶按系数穿透：权益桶 = Σ(基金市值 × 权益系数)；稳健桶 = Σ(债类与权益类基金市值 × (1 − 权益系数))；黄金桶 = Σ(黄金类基金市值 × (1 − 权益系数))。投入比例用净投入按同一套系数拆分，保证两列口径一致；三桶市值占比合计 100%。当前比例只统计在持基金（份额 > 0），已清仓基金不参与；缺最新净值的在持基金投入比例照常计入、市值按 0 计。对比表下方用「直接权益 + 债类穿透」说明权益桶构成；黄金类若被覆盖出非零权益系数，其权益部分计入权益桶但不在该两项内（默认系数为 0，正常数据下两项之和等于权益桶）。持仓列表的组级盈亏比例与年化仍按产品形态分组计算，**不做穿透**——历史组级收益不可重写，穿透只属于配置视图。

目标存放在配置桶层（`bucket_targets`），固定三行、逐行编辑。合计大于 0 且不等于 100% 时只警告，偏离按归一化目标计算；合计为 0 视为未配置、偏离为空。旧五类目标在首次出现新对比时剔除流动性、其余归一化后按固收+ 默认系数折算为三桶目标，展示一次确认，用户可接受或当场调整；确认前不写库。拒绝的替代方案：继续在旧五类上做穿透（目标与行动对象仍是五个类别，固收+/纯债的对立无法表达「同一风险暴露下的不同产品形态」）；只按产品形态分组做配置（无法合并固收+ 与纯债的稳健暴露）；给单只基金设目标金额（已被 ADR-0002 否决）。

**Consequences**: schema v5 新增 `bucket_targets`；旧五类字段、旧目标表与兼容映射在全部消费者迁移后由收缩票删除，最终模型只剩三层词汇。配置对比的偏离不再被非 100% 的旧目标系统性放大；已清仓基金不会凭残留净投入占住比例。基金配置页与手动抓取（第二期）修改产品形态 / 账本大类 / 权益系数时，配置视图随当前数据即时重算，不保留系数历史或生效日期。组级收益不穿透；若未来需要穿透后的历史收益，须另立 ADR 说明追溯口径。
