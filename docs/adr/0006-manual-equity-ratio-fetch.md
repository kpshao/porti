# 手动抓取权益系数：仅用户点击、固定公开数据源的最小联网边界

ADR-0003 要求新增联网能力前重审联网边界。第二期需要在基金配置页从公开数据获取「股票占净比（季报）」作为权益系数候选值。本 ADR 记录这次重审的结论：抓取仅由用户在基金配置页点击触发，在主进程执行，固定使用东方财富公开基金数据；不做后台、定时或启动自动抓取，不自动应用抓取结果。

数据源固定为两个公开页面：优先解析 `https://fund.eastmoney.com/pingzhongdata/{code}.js` 中的 `Data_assetAllocation`（股票 / 债券 / 现金占净比，近四个季度）；请求或解析失败时回退 `https://fundf10.eastmoney.com/zcpz_{code}.html` 的资产配置表格，按表头定位列并兼容 QDII 的「存托凭证占净比」列（计入股票占净比）。不使用已失效的 FundArchivesDatas zcpz 接口，也不接入其他行情源。

请求与响应约束：单次请求 10 秒超时；批量顺序执行，相邻基金之间间隔 300ms（同一基金主源失败时立即回退 F10）；不携带 Cookie、账号信息或 API key；响应按不可信数据处理——不执行脚本、不建 DOM，pingzhongdata 只做字符串定位 + `JSON.parse`，F10 只按标签与表头做纯文本解析；手动跟随重定向，每次跳转前校验 https 与两个固定域名；响应体按流读取，超过 2MB 立即取消。解析器与服务测试使用 golden payload，不联网。

候选值与写入：抓取结果只展示股票占净比、报告期与数据来源，用户点击「确认写入」后才更新权益系数。候选值只保存在主进程内存中，不写数据库也不持久化；确认时主进程以自己抓到的候选值决定报告期与来源，不信任渲染进程回传的报告期或抓取值。确认时未修改数值 → 系数来源记为抓取；修改过 → 来源记为手工；两种情况都保留报告期作为系数数据日期。重新抓取会替换候选值，抓取失败或用户忽略会清除候选值。抓取失败保留旧值并逐行报错，批量中单只失败不阻断其余基金。界面把抓取结果标为「股票占净比（季报）」而不是权益系数，可转债等股性部分由用户手工调整。拒绝的替代方案：启动或定时抓取（用户不知情的外联）、自动把抓取结果写入系数（静默覆盖手工调整）、在渲染进程直接联网（绕过主进程安全边界）、执行远端脚本或用 DOM 解析（扩大不可信输入的暴露面）、使用第三方行情源（新的凭据与稳定性依赖）。

**Consequences**: 应用只在用户点击「抓取 / 刷新全部」时访问东方财富公开数据；联网失败不阻塞任何本地功能。抓取能力依赖上述页面的结构与文本格式，数据源改版时解析器会失败并逐行报错，需要更新解析器与 golden payload。AI 联网边界仍按 ADR-0003 执行，本 ADR 不改变 AI 快照字段白名单或发送条件。
