# 云端 AI 采用默认关闭、按次显式发送的最小联网边界

porti 的定位是本地优先的基金仓位管理软件，但 AI 分析必须把数据交给第三方模型服务。选择把联网边界收敛为「用户显式配置 + 每次点击发送」：未配置 AI 时不发起任何请求；配置后也只有用户点击发送时，主进程才把「分析快照」发往用户填写的 OpenAI 兼容端点（`POST {baseURL}/chat/completions`），不做后台分析、定时请求或遥测。API key 用 Electron safeStorage 加密存入 `settings.json`，只在主进程解密，永不回传渲染进程、不进日志与快照；safeStorage 不可用时拒绝保存 key，不降级为明文。快照是固定字段白名单的 JSON，只含汇总、持仓明细、大类目标与偏离、集中度指标、全部流水、每只基金的区间收益摘要与数据新鲜度，不含密钥、数据文件路径与原始逐日净值序列，且发送前可预览。拒绝的替代方案：内置供应商 key 或云端中转（凭据与成本风险，违背本地优先）、默认开启或后台自动分析（用户不知情的数据外发）、直接发送数据库文件或原始净值序列（泄露路径且数据冗余）。

**Consequences**: AI 未配置或不可用时全部本地功能照常工作；数据外发的信任边界转移到用户选择的端点供应商；快照字段白名单是安全契约的一部分，扩展字段须同步更新 `CONTEXT.md` 与测试；未来新增联网能力或自动化分析须先重审本 ADR。
